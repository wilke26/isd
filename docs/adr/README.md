# Architecture Decision Records

Dieses Verzeichnis dokumentiert Architekturentscheidungen, die für mehrere
Einstiegspunkte oder Module des Systems gelten. Eine ADR beschreibt den Kontext,
die getroffene Entscheidung, verworfene Alternativen und die daraus folgenden
Konsequenzen.

## Statuswerte

- **Vorgeschlagen:** Die Entscheidung wird diskutiert und ist noch nicht bindend.
- **Akzeptiert:** Die Entscheidung gilt für neue Änderungen und Reviews.
- **Ersetzt:** Eine neuere ADR hat die Entscheidung abgelöst.
- **Verworfen:** Die vorgeschlagene Entscheidung wurde nicht übernommen.
